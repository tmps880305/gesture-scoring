# 手勢計數器 App — 專案需求規格

> 本文件給 Claude Code 參考，用於快速開發 MVP。請依此規格建立專案並實作功能。

## 1. 專案概述

一個 iPhone App，畫面中央大大顯示一個數字（0–99）。使用者透過**自拍鏡頭比手勢**讓數字 +1，透過**觸控下滑**讓數字 -1。

目標是快速完成可運作的 MVP，架構簡潔，不追求過度設計。

## 2. 技術架構

| 項目 | 選擇 |
|------|------|
| 前端框架 | React + TypeScript（使用 Vite 建立專案） |
| 手勢辨識 | MediaPipe Web — `@mediapipe/tasks-vision` 的 `GestureRecognizer` |
| 原生包裝 | Capacitor（iOS 平台） |
| 目標裝置 | iPhone（iOS） |

- **不要使用 Cordova**。
- 手勢辨識完全在裝置端執行，不需要後端與網路。

## 3. 功能需求

### 3.1 數字顯示
- 畫面中央以超大字體顯示目前數字。
- 範圍：0–99。
  - 99 時再 +1：維持 99（不循環）。
  - 0 時再 -1：維持 0（不變負數）。
- 初始值為 0。

### 3.2 畫面方向
- **鎖定橫向（Landscape）**，不允許轉為直向。
- 需在 iOS 原生設定（`Info.plist` 的 `UISupportedInterfaceOrientations`）限制為橫向，左右橫向皆可。
- 注意橫向時的瀏海／動態島 safe area，UI 元素不可被遮住。

### 3.3 手勢 +1（兩段式辨識）
使用前鏡頭（`facingMode: 'user'`）持續偵測手勢，流程如下：

1. **第一段**：偵測到 `Victory`（比 YA ✌️）→ 進入「等待第二段」狀態。
2. **第二段**：在等待狀態中偵測到 `Thumb_Up`（比讚 👍）→ 數字 +1，流程重置回第一段。
3. **逾時**：進入等待狀態後若 **3 秒**內沒偵測到 `Thumb_Up`，自動重置回第一段。
4. **冷卻**：成功 +1 後有 **1.5 秒**冷卻時間，期間不接受新的辨識，避免重複觸發。

防誤判規則：
- 某手勢需**連續數幀**（例如 3 幀以上）被判定，且信心分數 ≥ **0.7**，才算成立。
- 以上數值請集中定義為常數，方便調整。

狀態提示：
- 畫面上需有一個不干擾數字的小型提示，讓使用者知道目前階段（例如：「請比 ✌️」→「請比 👍」→「+1 成功」）。

### 3.4 觸控 -1
- 在畫面上（數字區域）**由上往下滑動** → 數字 -1。
- 需設定最小滑動距離門檻（例如 50px），避免誤觸。
- 一次滑動只減 1。

### 3.5 設定
- 畫面**右上角**放一個齒輪圖示（⚙️）。
- 點擊後開啟設定面板（Modal 或 Drawer 皆可）。
- 目前只有一個功能：**數字歸零**。
  - 建議加上確認步驟，避免誤按。
- 設定面板開啟時，暫停手勢辨識與滑動操作。

### 3.6 相機預覽（選配）
- 可在角落顯示小型相機預覽（鏡像顯示），方便使用者確認手是否在鏡頭內。
- 預覽不可遮擋數字與齒輪圖示。

## 4. 實作注意事項

### MediaPipe
- `runningMode` 使用 `VIDEO`，`delegate` 優先使用 `GPU`。
- **模型檔（`.task`）與 WASM 檔需打包在 App 的靜態資源內**，不要從 CDN 載入，確保離線可用。
- 辨識頻率不需每幀執行，約每秒 10–15 次即可，以節省電量與降低發熱。

### iOS / Capacitor
- `Info.plist` 必須加入 `NSCameraUsageDescription`（缺少會閃退）。
- `<video>` 標籤需加上 `playsinline` 與 `muted`。
- 自拍預覽以 CSS `transform: scaleX(-1)` 鏡像顯示（不影響辨識）。
- WKWebView 可能出現兩次相機權限詢問（App 層 + 網頁層），若發生需在原生端處理。
- App 進入背景時停止相機，回到前景時恢復。

## 5. 建議專案結構

```
src/
  components/
    CounterDisplay.tsx   # 數字顯示 + 滑動手勢
    SettingsButton.tsx   # 右上角齒輪
    SettingsPanel.tsx    # 設定面板（歸零）
    GestureStatus.tsx    # 手勢階段提示
    CameraPreview.tsx    # 相機預覽（選配）
  hooks/
    useCamera.ts         # 前鏡頭串流
    useGestureRecognizer.ts  # MediaPipe 初始化與辨識迴圈
    useGestureSequence.ts    # 兩段式狀態機（Victory → Thumb_Up）
    useSwipeDown.ts      # 下滑偵測
  constants.ts           # 門檻值、逾時、冷卻時間等
  App.tsx
public/
  models/                # gesture_recognizer.task
  wasm/                  # MediaPipe WASM 檔
```

## 6. 驗收標準

- [ ] App 啟動後鎖定橫向，數字顯示 0。
- [ ] 比 ✌️ 後再比 👍，數字 +1。
- [ ] 只比 👍（沒有先比 ✌️）不會 +1。
- [ ] 比 ✌️ 後超過 3 秒才比 👍，不會 +1。
- [ ] 成功 +1 後的冷卻期間不會重複加。
- [ ] 由上往下滑動，數字 -1；0 時不再減少。
- [ ] 數字到 99 時不再增加。
- [ ] 點右上角齒輪可開啟設定，執行歸零後數字變 0。
- [ ] 在 iPhone 實機上可正常取得前鏡頭並辨識手勢。
- [ ] 離線狀態下手勢辨識仍可運作。
